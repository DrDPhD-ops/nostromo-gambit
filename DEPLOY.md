# Развёртывание

Сервер — Node 22+ с одной зависимостью (`chess.js`) и отдельными процессами
Stockfish. В Docker-образ движок ставится при сборке, `npm run setup` там не нужен.

## Переменные окружения

| Переменная | Значение |
|---|---|
| `APP_PASSWORD` | общий пароль на вход. **Обязателен, если `HOST` не loopback** — иначе сервер не стартует |
| `HOST` | локально `127.0.0.1`, в Docker `0.0.0.0` |
| `PORT` | по умолчанию `7777`; на Render приходит от платформы |
| `ENGINE_WORKERS` | размер пула движков. По умолчанию — от числа ядер; в Docker `1` |
| `NOSTROMO_HOME` | где лежат движок и служебные файлы; в Docker `/home/node/.nostromo` |
| `COOKIE_SECURE` | `true` / `false` / `auto` (по `X-Forwarded-Proto`) |
| `SESSION_TTL_DAYS` | срок жизни сессии, по умолчанию 30 |

Без `APP_PASSWORD` на `127.0.0.1` всё работает как раньше: вход не включается.

## Почему ENGINE_WORKERS=1 в контейнере

`os.cpus()` в контейнере видит все ядра хоста, а не выделенную квоту, и пул вырос бы
до пяти воркеров. Замер Stockfish 19: ~200 МБ бинаря с нейросетями общие для всех
процессов, плюс 60–75 МБ собственной памяти на каждый. Один воркер, аналитический
движок и Node укладываются примерно в 400 МБ — это предел для планов с 512 МБ.
На машине с 2 ГБ можно ставить 3–4.

## Docker

```bash
docker build -t nostromo-gambit .
docker run -p 7777:7777 -e APP_PASSWORD=... nostromo-gambit
```

Сборка сама скачивает `stockfish-linux-*-universal.tar.gz` из релиза `sf_19`, сверяет
sha256 и падает, если бинарь не ответил по UCI (`scripts/install-engine-docker.mjs`).

## Render.com

1. **New → Web Service**, подключить репозиторий. Render сам увидит `Dockerfile`.
2. Branch — `master`, Root Directory — пусто, Health Check Path — `/health`.
3. Переменные: `APP_PASSWORD`, `ENGINE_WORKERS=1`, `COOKIE_SECURE=true`.
   `PORT` не задавать.

Либо **New → Blueprint** — всё описано в `render.yaml`, спросит только пароль.

Про тарифы: поиск десанта упирается в процессор, бюджеты пересчитываются от
измеренной скорости при каждом старте. На free (0.1 CPU) игра работает, но десант
ищется очень долго, и сервис засыпает после 15 минут простоя. Starter (0.5 CPU) —
разумный минимум.

## Что стоит знать

- **Партия одна на весь сервер.** Все, кто вошёл по паролю, видят и двигают одну и ту
  же доску. Это исходная архитектура (см. README, «Известные ограничения»).
- **Состояние в памяти.** Перезапуск контейнера начинает партию заново.
